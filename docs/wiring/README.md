# QuickRescue Wiring & Hardware Interfacing

This directory documents wiring schematics, pin mappings, and power budgeting for:
1. **Communication Tower:** Raspberry Pi 4 GPIO header, LoRa SPI Hat, P10 display via HUB12, relay drivers for Industrial Siren, Tri-color indicator, solar MPPT connection.
2. **Handy Device:** ESP32 pinout to SX1276/78 LoRa module, NEO-6M GPS serial, I2C bus (SSD1306 OLED & MPU6050), push buttons, and TP4056 charging circuit.
